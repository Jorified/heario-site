How to add an AI chatbot to your Webflow website

Webflow's site-wide Custom Code setting adds code to every page. Paste your chat code into the footer code box, publish, and the chat is live.

Takes about 5 minutes · You only do it once · The chat then appears on every page

Before you start

  • You'll need a Heario account. Start a free trial if you don't have one yet.
  • In your Heario dashboard, add your website address under 3. Your website and click Save. The chat only runs on the addresses you list.

Steps

  1. Log in to your Heario dashboard, go to 4. Add it to your website and click Copy code.
  2. Open Site settings → Custom code.
  3. Paste the code into Footer code.
  4. Click Save, then Publish your site.

Good to know: Custom code needs a paid Webflow site plan. If visitors also use your yoursite.webflow.io address, add it in section 3 too.

Check it's working

Open your website in a private or incognito window. The chat bubble should appear in the bottom corner within a few seconds. It won't show inside your Webflow editor or preview, only on your published site.

Chat bubble not showing?

  • Make sure you published or saved the change.
  • Check that the exact address you're visiting is listed under 3. Your website in your Heario dashboard, then click Save.
  • Check "Chatbot is switched on" is ticked in your dashboard.
  • Paste the code only once. If you've also added it to a page block, remove that copy.
