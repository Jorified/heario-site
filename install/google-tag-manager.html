How to add an AI chatbot using Google Tag Manager

If your website already loads Google Tag Manager, you can add the chat as a Custom HTML tag without touching your website's code. It works with any website builder that supports Tag Manager.

Takes about 5 minutes · You only do it once · The chat then appears on every page

Before you start

  • You'll need a Heario account. Start a free trial if you don't have one yet.
  • In your Heario dashboard, add your website address under 3. Your website and click Save. The chat only runs on the addresses you list.

Steps

  1. Log in to your Heario dashboard, go to 4. Add it to your website and click Copy code.
  2. In Tag Manager, go to Tags → New.
  3. Click Tag Configuration and choose Custom HTML.
  4. Paste the code.
  5. Click Triggering and choose All Pages, then Save.
  6. Click Submit, then Publish.

Good to know: Use this if your website already loads Google Tag Manager. It works with any builder that supports it.

Check it's working

Open your website in a private or incognito window. The chat bubble should appear in the bottom corner within a few seconds. It won't show inside your website editor or preview, only on your published site.

Chat bubble not showing?

  • Make sure you published or saved the change.
  • Check that the exact address you're visiting is listed under 3. Your website in your Heario dashboard, then click Save.
  • Check "Chatbot is switched on" is ticked in your dashboard.
  • Paste the code only once. If you've also added it to a page block, remove that copy.
