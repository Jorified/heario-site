Can you add an AI chatbot to a GoDaddy website?

Whether you can add a chat to a GoDaddy website depends on which kind of GoDaddy site you have. Here's how to tell and what to do.

What to do

  1. GoDaddy's Websites + Marketing builder doesn't currently let you add code to every page, so the floating chat bubble can't be added there.
  2. If your GoDaddy site runs on WordPress, use the WordPress steps instead.

Good to know: Email support@heario.ai if you're on GoDaddy and we'll look at the options with you.
